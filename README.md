# 🚀 B2B Leads Контракты СВО

> **B2B-лендинг** компании по генерации и продаже квалифицированных лидов для заключения контрактов СВО по всей территории РФ.

---

## 📋 О проекте

Сайт разработан как технологичный и убедительный B2B-инструмент для привлечения партнеров и заказчиков. Продукт ориентирован на обеспечение стабильного потока проверенных заявок от мужчин в возрасте от 18 до 63 лет, выразивших готовность подписать контракт СВО. 

**Ключевые преимущества предложения на сайте:**
* **Масштаб:** 300+ уникальных квалифицированных кандидатов ежедневно по всей РФ.
* **Глубокая валидация:** Каждый лид проходит проверку оператором контакт-центра (критерии: возраст, прохождение по здоровью, отсутствие критических судимостей).
* **Безопасность:** Гарантированная бесплатная замена невалидных лидов (брака) строго по договору.

## 🛠️ Технологический стек

Проект реализован на базе легковесных и ультрасовременных фронтенд-технологий для обеспечения максимальной скорости загрузки:
* **HTML5** — семантическая и SEO-ориентированная разметка.
* **Formspree.io** — Отправка заявок на Почту.
* **CSS3** — современный адаптивный UI с поддержкой темной/AI-native эстетики и плавных микро-взаимодействий.
* **JavaScript (Vanilla JS)** — чистый код без тяжелых зависимостей для обработки интерактивных элементов и отправки форм.
* **Font Awesome / Lucide Icons** — современные векторные иконки.
* **Git + GitHub** — контроль версий и совместная разработка.
